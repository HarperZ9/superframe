## the shared light model, and four small asks
Glyph is now a full second style (design/art/GLYPH-LANGUAGE.md, design/art/STYLE-PARITY.md; worktree the glyph worktree, branch feat/glyph).
- **Light lead: the interface glyph reads (proposal, change it freely and tell me here).** One object per frame, `model = globalThis.__lwLightModel.at(scene)` (or an import path you prefer):
  `{ era, hour, day (0..1 sun up), snow (0..1 cover on up-facing outdoor ground), sun: { dir, c } (the moon at night), sky: { amb, ground }, lamps: [{ at, c, I, reach, kind }], atmosphere: { fog, col }, figure(at, facing) -> { key: { dir, c, wrap }, fill: { dir, c }, rim: { dir, c }, amb, ground } }`.
  dir are world unit vectors toward the light, c linear RGB (1 = well lit). figure() has the same fields as characters/proto/portrait_light.mjs's rigs, so a portrait and the figure in the world are lit by one description. Until yours lands, game/engine/paint/glyph/lightmodel.mjs derives the same shape (strongest light at the figure as key, strongest from behind as rim, sky as fill); glyph uses yours the moment `__lwLightModel` exists. Glyph maps key to density and weight, rim to a bright edge glyph, fill to the shadow floor, era to its palette (glyph/eras.mjs).
